# Job Scheduling and Graph Coloring Algorithms

This repository contains the source code and computational implementations used in our research on graph coloring and job scheduling.

## Algorithms

The repository includes implementations of the following algorithms:

- Backtracking
- Exact DSATUR
- Greedy
- DSATUR
- RLF
- Memetic Algorithm
- Simulated Annealing (SA)
- Tabu Search
- Ant Colony Optimization (ACO)
- SAHGC

## Implementation

The algorithms are implemented in Python and are designed for experimental evaluation on graph coloring and examination timetabling problems.
